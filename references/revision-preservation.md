# 反复修改 Word：用户修改保留流程

编辑已有 Word 时读取。用户在文件里的修改是任务上下文的一部分，排版优化必须保留其表达的意图。

## 1. 确定比较基准

- 以用户明确指向或最新提供的文件为工作基准。不要只凭文件名中的“最终”或修改时间，认定哪个版本代表用户意图。
- 有上一版时，将“上一版 → 用户修改版”的差异与本次要求一起阅读；差异用于辨认意图，不用于把新版回滚成旧版。
- 只有当前文件时，检查现存格式、批注和修订。未开启修订且已经删除的文字无法仅靠当前文件恢复，不得虚构已完成历史比较。
- 大改前保留原文件，并在新版本上工作。旧 `.doc` 若需转换，在获准编辑的范围内转换副本，并检查转换是否保留批注、修订和公式。

## 2. 既看结构，也看页面

至少读取正文、表格、公式、页眉页脚中本次涉及的内容，并检查：

| 对象 | 要记录的信息 | 默认处理 |
|---|---|---|
| 荧光笔、字体颜色、底纹 | 颜色、原文、精确范围、上下文 | 保留含义，明确后才升级样式 |
| 加粗、下划线、删除线 | 是否表达重点、疑问或删除意图 | 不作为格式噪音直接清掉 |
| Word 批注 | 内容、锚定文字、未解决状态 | 逐条处理，保留关联和待办 |
| 行内括号批语 | 如“这里不懂”“补英文”“删掉？” | 结合上下文区分命令与疑问 |
| 修订插入/删除/移动 | 内容、位置、修订状态 | 不批量接受或拒绝 |
| 段落缺失与重排 | 和旧版的差异、对应上下文 | 保持用户删除与结构选择 |

先形成简短工作清单：`标题/文本锚点 | 原标记或改动 | 已知意图/待辨认 | 处理方式 | 新版对应位置`。页码会随排版变化，不能只用页码定位。

不要只读 `.paragraphs[].text` 或导出的纯文本就声称检查过标记。根据工具能力检查 Word 对象、连接的文档会话或 OOXML，并查看实际页面。

需要检查 DOCX 内部时，留意：

- `word/document.xml` 及本次涉及的页眉、页脚、脚注等内容部件。
- `w:highlight`、`w:color`、`w:shd`、`w:strike` 以及样式继承、主题色；缺少直接颜色属性不代表页面没有颜色。
- `word/comments*.xml`、批注范围起止、引用标记和相关关系文件。
- `w:ins`、`w:del`、`w:delText`、`w:moveFrom`、`w:moveTo` 及段落/表格属性中的修订；提取当前正文时不要把删除文本当成有效正文拼回。
- 批注、修订及形状可能是编辑库不完整支持的功能。优先局部修改，避免把全文抽成纯文本再重建；保存后检查相关部件和关系仍有效。

## 3. 允许的升级与保留边界

**升级的是呈现方式，不能改变用户标记的含义和范围。**

- 已知为整段“重点”的黄色荧光笔，可升级为“提示-重点”段落样式；颜色浅、左边框清晰，并保留标签。
- 仅标了一个名词，就用字符样式保留这个名词的突出效果；不要把整段都改成同一重点，使原标记失去精确性。
- 颜色含义未知时保留原颜色和范围。不能默认红色就是错误、蓝色就是结论，也不能仅为凑成 3 类而合并用户不同类别。只有影响后续处理时才向用户澄清。
- 用户明确要求保留荧光笔时，保留荧光笔；一般指南中“改用段落底纹”的建议不能覆盖这个要求。
- 批注中的明确修改要求属于本次编辑任务时落实到正文；问题或疑虑不能凭猜测变成确定结论。未解决的批注继续保留。
- 完成批注意图后，默认保留可追溯联系，不擅自删除全部批注、标为已解决或改变所有修订状态；用户要求清稿/接受修订时再按范围处理。
- 如果必须移动或重写批注锚点，把批注重新关联到新文本，不能留下悬空引用。确实无法原位保留时，保护原稿并明确说明迁移位置，不静默丢弃。
- 用户删除过的段落在新版中仍应删除，包括旧稿、摘要或素材里还能找到的同义段落。删除影响公式定义、编号或上下文时先修复引用；必须补回实质内容才可继续时，明确说明冲突并询问。
- 若技术核查发现用户改动有误，说明原文、证据与建议；不以“保留修改”为由传播已知错误，也不无说明地覆盖用户选择。

## 4. 补英文名词

对学习所需的专业术语、用户特别标出的名词或“补英文”批注，使用“中文（English term）”。优先放在首次出现或可独立阅读的复习位置。

- 使用本课程/原资料采用的译名，全文统一；英文已有且准确时不重复添加。
- 对缩写首次给全称，例如“有限元法（finite element method, FEM）”。
- 普通日常词不必加英文；不把半句中文改成半句英文；不能把批注内容直接当作待翻译的正文。
- 词义不明确时核查资料或标为待核实，不凭字面猜术语。

## 5. 改后逐项核对

1. 对照修改清单，确认每个用户标记在新版中仍有对应内容和意义。
2. 对照旧版差异，检查已删除内容没有复活，已改数字和公式没有退回旧值。
3. 检查批注锚点、修订状态、公式邻接文字和表格内容，没有因重新生成而丢失。
4. 查看页面，确认高亮/新样式清晰可辨，标记范围没有扩大或缩小。
5. 交付时概括“保留了什么、升级了什么、还有什么待确认”；仅报实际检查结果。

### 行为示例

用户把“条件数”标黄、批注“补英文”，并删掉旧版一段推导：新版保留这个名词的强调，补为“条件数（condition number）”，保持推导删除。

用户用红、蓝两色区分自己还没解释的复习状态：先保持两色及原范围，不擅自映射成“易错”和“结论”。

仅收到一份没有修订记录的最新版：可以检查当前高亮和批注，但不能声称查出了用户之前删除的所有段落。

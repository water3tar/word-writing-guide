# Word Writing Guide

用于中文 Word 技术文档写作与修改的 AI 助手技能，重点处理可编辑公式、统一样式、用户批注与版本差异。

## 适用任务

- 编写课程讲义、实验报告、设计说明、论文小节和知识库条目。
- 将所有方程与数学公式转为 Word 原生公式，并整理竖排矩阵、标题、提示框、图表和交叉引用。
- 反复修改 Word 时，先检查高亮、颜色、批注、修订和删除，再保留或改进其呈现。
- 在需要时为专业术语补充英文，并核查关键数据和导出页面。

简历、信件等文档只采用适用的规则，不强制套用技术讲义结构。

## 安装与使用

将整个 `word-writing-guide` 文件夹放入所用助手支持的技能目录，保留以下文件结构：

```text
word-writing-guide/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── revision-preservation.md
    ├── writing-spec.md
    └── quality-checklist.md
```

在支持显式技能调用的工具中，可以这样提出任务：

> 请使用 $word-writing-guide 修改这份 Word。先检查我添加的高亮、批注和删除，再统一公式与排版。

元数据已允许自动匹配，是否自动调用取决于使用该技能的助手。技能提供写作和检查流程；编辑、公式处理及页面渲染需要助手具备相应的文档工具。

## 主要规则

- 先读用户指定的最新原稿；有可用旧版时，再比较历史变化。
- 改进样式时保留用户标记的意义和精确范围，不擅自恢复已删除内容。
- 所有方程、等式、不等式和数学公式都使用可编辑的 Word 原生公式（OMML），包括行内的简单式子；矩阵保留真实行列结构。
- 用样式管理字体、标题和提示；默认采用 Arial / 宋体，数学字体为 Cambria Math。
- 保持术语、符号、单位与有效数字一致，交付前检查文档结构和实际页面。

用户明确要求、指定模板和任务范围优先于默认参数。

## 阅读顺序

从 [SKILL.md](SKILL.md) 开始。修改已有文档时读[修改保留流程](references/revision-preservation.md)，创建或调整版式时读[写作规范](references/writing-spec.md)，交付前读[检查清单](references/quality-checklist.md)。
